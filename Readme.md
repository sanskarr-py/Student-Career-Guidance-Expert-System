# 🎯 Student Career Guidance Expert System


A simple **Python + Tkinter** expert system that helps students explore suitable career paths based on their interests.


### ✨ Features


- 🎓 20 interest-based questions
- 📊 Weighted career matching
- 🏆 Top 3 career recommendations
- 📈 Match percentage
- 📚 Suggested courses
- 🖥️ Simple Tkinter GUI
- 🔄 Clear and reset option


### 🧠 How It Works


The system takes the student's interest levels and compares them with a **career knowledge base** using weighted rules.

       ↓
